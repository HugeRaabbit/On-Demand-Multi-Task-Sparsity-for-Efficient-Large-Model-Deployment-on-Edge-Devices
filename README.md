# On-Demand Multi-Task Sparsity for Efficient Large-Model Deployment on Edge Devices

## Datasets

* Bosch Small Traffic Lights Dataset:
[https://zenodo.org/records/12706046](https://zenodo.org/records/12706046)

* CODA Dataset:
[https://coda-dataset.github.io/](https://coda-dataset.github.io/)

* nuScenes Dataset:
[https://www.nuscenes.org/](https://www.nuscenes.org/)


> **Note**
> This repository currently contains demonstration code for two core components of the project:
>
> 1. **Overlap-Aware Multi-Task Sparsity Alignment** — a greedy task-aware layer/block removal procedure that encourages sparse structures to overlap across related tasks.
> 2. **Task Switching** — an incremental layer-switching prototype that measures the cost of switching between sparse task-specific sub-models.
